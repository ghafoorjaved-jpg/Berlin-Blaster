# Privacy Policy — Berlin Word Blaster

Last updated: 18 September 2026

Berlin Word Blaster is a language-learning game. It does not require an account.

## Data we collect

The game runs on your device. It does **not** collect names, emails, or payment data.

Score and progress may be stored only on the device (for example in memory while you play).

Speech uses the device’s built-in text-to-speech. That stays on the device unless the OS vendor sends it elsewhere (that is outside this app).

## Internet

If you install the Play Store wrapper as a Trusted Web Activity, the game may load from the URL you publish (GitHub Pages). No extra analytics are bundled in this package.

## Children

The game is suitable for language learners including children when used with a parent. Do not submit personal information through the app — there is no form for that.
